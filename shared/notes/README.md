# shared/notes

Everything the family records lives here, in plain Markdown.

- `my-notes.md` - the parent's running notes (my-notes skill)
- `teacher-notes.md` - notes from school, by class and teacher (teacher-notes skill)
- `reports/` - the pasted source documents from intake (IEP, Functional Capacity Assessment, other), saved as dated text files

Nothing here is sent anywhere. Back this folder up like any other family document.
