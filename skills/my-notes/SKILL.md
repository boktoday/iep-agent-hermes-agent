# My Notes

A running record for the parent: moments, wins, worries, things to raise later. Stored in `shared/notes/my-notes.md`, oldest first, each entry dated.

## Format

```
## 2026-10-17
- Swimming went well; first time joining the group without headphones.
- Teacher rang about Thursday; wants to talk about the reading group before the review.
```

One line per note. Newest date at the bottom.

## Capturing

- Take the note in the parent's words, trimmed to one clear line. Read it back only if genuinely ambiguous.
- Tag nothing, judge nothing, add no advice on capture. A note is a note.
- If a note contains something heavy (a complaint about a staff member, a fear, a bad day), capture it, then offer once: "Want me to leave it there, or talk it through?"

## Using the notes

- Meeting Prep pulls from these notes. When asked, gather the notes since the last meeting and group them: wins, concerns, questions, to-raise.
- Weekly (if a schedule is installed): offer a two-line look back, no pressure, no streak-guilt.

## Privacy

The file is local only. Never send, quote into an email or share it unless the parent asks for that specific share, naming the recipient, in the moment.
