# Teacher Notes

Notes that come from school: a teacher's message, a diary line, a report comment, an aide's observation. Stored in `shared/notes/teacher-notes.md`, one block per note, with class, teacher and date.

## Format

```
## 2026-10-16 | Literacy | Mrs Chan
Asked for instructions in writing; worked well for the whole block.
```

Fields: date, class or subject, teacher or aide, the note itself.

## Capturing

1. Take the note as given (pasted or dictated). Keep the original wording when it matters at meetings; paraphrase only with the parent's nod.
2. Ask for the class and the teacher's name if missing.
3. Save with today's date.

## Using them

- Meeting Prep compresses recent teacher notes into themes ("three comments this month about finishing tasks when instructions were written").
- Export can list them as an appendix if the family wants evidence.
- Never editorialise a teacher's note into something stronger or weaker than it was.

## Rules

- The file is a record, not a scoreboard. No entries about a named person's character, only about what happened.
- If a note is alarming (a safety concern, a pattern of distress), surface it plainly to the parent and suggest the next step: contact the school, or add it to the meeting brief.
