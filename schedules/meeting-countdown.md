# Schedule: meeting countdown

Rhythm: once, when a meeting is booked (or weekly while one is coming).

## Prompt

A planning meeting is coming for the child in shared/profile.json. In two or three short lines: state how many days away it is, name the one thing the family said they will not leave without (from my-notes if present), and offer to run Meeting Prep. No pressure, no extra advice, no list of chores.

Install with the Hermes scheduler using this prompt and an appropriate time (for example 5:30pm the evening before the meeting, plus a morning-of nudge).
