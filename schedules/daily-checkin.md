# Schedule: daily check-ins

Rhythm: mornings on school days, optional evenings.

## Morning prompt

One short message for the parent of the child in shared/profile.json. Ask a single light question about today ("Morning. Anything about today we should know about?"). If they reply with something worth keeping, offer once to save it to My Notes. If they do not reply, send nothing further. Never more than one sentence plus the question.

## Evening prompt (optional)

"One line from today, if you have it." If they reply, save to shared/notes/my-notes.md dated today, award MY_NOTE sparks if gamification is enabled, and confirm in three words max.

## Rules

Respect quiet hours and the "quiet please" pause (see the check-ins skill). No streak guilt, no follow-ups to unanswered messages.
